# The copyable artifact is an always-complete options object, not a snippet or a diff

Alternatives considered: a full working component snippet (noisier, duplicates what docs generators do), a raw JSON dump (what the official examples playground emits — not paste-runnable), and a changed-keys-only object (clean but hides options the user didn't discover). We decided the artifact is an options object literal containing **every in-scope option with its current value, defaults included** — it doubles as reference material and is copy-paste ready — with `container: '#waveform'` as a placeholder for the target element. When plugins are enabled, the few required `import` lines are prepended (e.g. `import TimelinePlugin from 'wavesurfer.js/plugins/timeline'`) because `plugins: [TimelinePlugin.create({...})]` is not runnable without them.
