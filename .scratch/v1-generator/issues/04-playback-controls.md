# 04: Playback controls

**What to build:** a simple play/pause control near the Preview plus the interactive waveform (click/drag to seek), so the user can judge progress, cursor, and hover behavior during real playback (US 13).

**Blocked by:** 03.

**Status:** ready-for-agent

- [ ] A visible play/pause control sits near the Preview and starts/stops the loaded audio
- [ ] Clicking or dragging the waveform seeks to the corresponding time
- [ ] Cursor and hover behavior can be observed during actual playback
